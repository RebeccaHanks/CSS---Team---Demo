Form Control Styling Demo

A teaching demo for showing how to style form controls while still keeping them usable and accessible.

1. Native Controls vs Custom Controls

✅ Native First 
input {
  accent-color: var(--blue);
}

Native controls are easier because the browser already handles a lot of the accessibility.

⚠️ Custom From Scratch 
input[type="checkbox"] {
  appearance: none;
}

When you remove the native style, you have to rebuild the whole control yourself.

2. Basic Form Markup

Every input should have a label. The for and id should match. 

<label for="name">Name</label>
<input type="text" id="name" name="name" />

3. Custom Select Arrow

You can style the select box, but not the dropdown menu. This example removes the browser arrow and adds a custom one. 

select {
  appearance: none;
  background-image: url("data:image/svg+xml,...");
  background-repeat: no-repeat;
  background-position: right 1rem center;
  padding-inline-end: 2.5rem;
}

4. Caret Color

The caret is the blinking cursor inside a text box. We can make it match our theme color. 

input,
textarea {
  caret-color: var(--blue);
}

5. One Focus Style

Different browsers show different focus rings. This makes all form controls use one matching focus style. 

input:focus-visible,
select:focus-visible,
textarea:focus-visible {
  outline: 2px solid var(--blue);
  outline-offset: 3px;
}

6. Styled Range Slider

Range sliders need special CSS because Chrome/Safari and Firefox use different pseudo-elements. 

input[type="range"]::-webkit-slider-thumb {
  appearance: none;
  background: var(--blue);
  border-radius: 50%;
}

7. Full Demo Form

This form uses labels, a custom select arrow, caret color, a styled range input, and one shared focus style.

8. Teaching Checklist

  1. Explain why native form controls are usually the best starting point.
  2. Show what appearance: none does.
  3. Explain why custom controls need extra accessibility work.
  4. Show the custom select arrow.
  5. Show the caret color inside a text input.
  6. Tab through the form to show the shared focus ring.
  7. Explain why range sliders need browser-specific CSS.
