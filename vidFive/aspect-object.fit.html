Aspect Ratio and Object Fit Demo

Demo for understanding aspect-ratio, object-fit, object-position, card thumbnails, and responsive video boxes.

1. The Main Problem

Images have their own natural shape. But grid and flex containers can make boxes that are different shapes.

Problem: If an image is forced into the wrong shape, it can stretch, crop, or leave empty space.

2. Without the Right Properties

This image is forced into a box. It fills the space, but it gets stretched and looks wrong.

❌ Stretched Image 
img {
  width: 100%;
  height: 220px;
}
✅ Better Image 
img {
  width: 100%;
  height: 220px;
  object-fit: cover;
}

3. What aspect-ratio Does

aspect-ratio controls the shape of an element. It can make something a square, widescreen, or any other ratio.

Square

1 / 1
aspect-ratio: 1 / 1;

Video Shape

16 / 9
aspect-ratio: 16 / 9;

Card Shape

4 / 3
aspect-ratio: 4 / 3;
Simple idea: aspect-ratio controls the shape of the box.

4. object-fit Values

object-fit controls how the image fills the box.

fill

Fills the box, but can stretch the image.

object-fit: fill;

cover

Fills the box and crops extra parts.

object-fit: cover;

contain

Shows the whole image but may leave space.

object-fit: contain;

none

Keeps the image its original size.

object-fit: none;

5. Best Pattern for Card Images

This is the pattern we will probably use the most for card thumbnails. 

.card img {
  width: 100%;
  aspect-ratio: 16 / 9;
  object-fit: cover;
  object-position: center;
  display: block;
}

6. Video Boxes That Stay 16:9

A video or iframe should keep its shape when the screen changes size. aspect-ratio makes this easy. 

.video-embed {
  width: 100%;
  aspect-ratio: 16 / 9;
}

.video-embed iframe {
  width: 100%;
  height: 100%;
}

7. object-position

When object-fit: cover crops an image, object-position chooses which part stays visible.

Center

object-position: center;

Top

object-position: center top;

Bottom

object-position: center bottom;
Tip: Use object-position: center top; for people photos so faces do not get cut off.

8. Final Teaching Checklist

  1. aspect-ratio controls the shape of the box.
  2. object-fit controls how the image fits inside the box.
  3. cover fills the box but may crop.
  4. contain shows the whole image but may leave space.
  5. fill can stretch and distort the image.
  6. object-position controls which part of the image stays visible.
  7. The best card image pattern is usually aspect-ratio plus object-fit: cover.
