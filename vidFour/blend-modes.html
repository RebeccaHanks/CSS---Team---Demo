CSS Blend Modes Demo Page

Demo for understanding background-blend-mode, mix-blend-mode, blend mode families, text readability, and isolation.

1. What Are Blend Modes?

Blend modes control how two layers of color mix together. Instead of one layer simply covering another, the browser combines their colors to create effects like darkening, lightening, contrast, or color changes.

Simple idea: Blend modes mix a top layer with a bottom layer.

2. The Two CSS Blend Properties

background-blend-mode

Blends an element’s own background layers together. This is usually safer and easier to control. 

.hero {
  background:
    blue,
    url('/images/hero.jpg') center / cover;
  background-blend-mode: multiply;
}
mix-blend-mode

Blends the whole element with whatever is behind it on the page. This is powerful, but less predictable. 

.overlay-text {
  mix-blend-mode: screen;
}

3. Blend Mode Families

You do not need to memorize every blend mode formula. Instead, learn the main groups.

Darken

multiply
multiply

Makes colors darker. White tends to disappear.

Lighten

screen
screen

Makes colors lighter. Black tends to disappear.

Contrast

overlay
overlay

Adds contrast by mixing darkening and lightening.

Component

color
color

Changes color while keeping some original image detail.

4. background-blend-mode: Color Wash

This example places a solid color over a photo and blends them together. The image becomes darker and tinted.

Color Wash Over a Photo

/* Color wash over a photo */
.hero {
    background:
        oklch(0.45 0.2 260),
        url('/images/hero.jpg') center / cover;
    background-blend-mode: multiply;

    /* background-position: center; */
    /* background-size: cover; */
}

5. background-blend-mode: Gradient Duotone

This example blends a warm-to-cool gradient over a photo. It creates a duotone effect without editing the image in Photoshop.

Gradient Duotone Effect

/* Gradient duotone: warm to cool across the image */
.hero {
    background:
        linear-gradient(to right, oklch(0.5 0.2 30), oklch(0.4 0.2 280)),
        url('/images/hero.jpg') center / cover;
    background-blend-mode: overlay;
}

6. mix-blend-mode

mix-blend-mode blends the whole element with whatever is behind it. This example uses text that blends with the background.

Blended Text 
.overlay-text { mix-blend-mode: screen; color: oklch(0.9 0 0); }

7. Text Legibility Warning

Blend modes on text can be risky because the text changes depending on the background behind it. It may be readable in one place and unreadable in another.

❌ Risky

This blended text may disappear.

✅ Safer

8. Isolation: Controlling the Blend Scope

Without isolation, a blended element can interact with things outside its card. With isolation, the blending stays inside the card.

❌ Without Isolation
Blends too far
✅ With Isolation
Stays contained
/* Without isolation: blend leaks through to the page background */ .card { position: relative; } .card .overlay { mix-blend-mode: multiply; /* This blends with the card AND whatever is behind the card */ } /* With isolation: blend stays inside the card */ .card { isolation: isolate; } .card .overlay { mix-blend-mode: multiply; /* This only blends with content inside the card */ }
Rule of thumb: When you use mix-blend-mode, usually add isolation: isolate to the nearest parent container.

9. Final Teaching Checklist

  1. Explain that blend modes mix two layers of color.
  2. Show the difference between background-blend-mode and mix-blend-mode.
  3. Demonstrate darken, lighten, contrast, and component blend families.
  4. Show a hero image with a color overlay.
  5. Show a hero image with a gradient overlay.
  6. Warn that blended text can fail accessibility contrast.
  7. Show why isolation: isolate keeps blending under control.
