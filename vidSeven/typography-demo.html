Variable Font Axes Demo

A teaching demo for explaining how one variable font file can control weight, width, slant, custom axes, animation, and performance.

1. Static Fonts vs Variable Fonts

❌ Static Font Files 
regular.woff2
bold.woff2
italic.woff2
bold-italic.woff2

Static fonts usually need a separate file for each weight or style.

✅ Variable Font File 
recursive-variable.woff2

One variable font file can create many weights and styles.

2. Loading a Variable Font

@font-face {
  font-family: 'Recursive';
  src: url('/fonts/recursive-variable.woff2')
       format('woff2-variations');
  font-weight: 300 1000;
  font-style: normal;
  font-display: swap;
}

The important part is font-weight: 300 1000;. This means the font can use any weight between 300 and 1000.

3. Weight Axis

The weight axis controls how thick or thin the letters are. 

.light {
  font-weight: 300;
}

.bold {
  font-weight: 900;
}

4. Width Axis

The width axis changes how narrow or wide the letters are. 

.condensed {
  font-stretch: 75%;
}

.wide {
  font-stretch: 125%;
}

5. Slant and Italic

Slant tilts the letters. Italic uses a true italic style when the font has one. 

.slanted {
  font-style: oblique 10deg;
}

.italic {
  font-style: italic;
}
Slanted Text
Italic Text

6. Custom Axes

Some variable fonts have custom axes. These use font-variation-settings. 

.casual-mono {
  font-variation-settings:
    'MONO' 1,
    'CASL' 0.8;
}
Custom axes depend on the font you choose.
Important: Use normal CSS properties like font-weight when possible. Use font-variation-settings for custom axes.

7. Animating an Axis

Axis values are numbers, so they can be animated. Hover over the text below. 

.animated-heading {
  font-weight: 400;
  transition: font-weight 0.3s ease;
}

.animated-heading:hover {
  font-weight: 900;
}

8. Performance Tradeoff

Only 2 Weights

bold.woff2

If you only need two weights, static font files might be smaller.

Many Weights

variable-font.woff2

If you need several weights, one variable font can be better.
