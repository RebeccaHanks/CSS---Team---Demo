Pure CSS Icons Demo Page

Learn how to build simple icons with CSS borders, pseudo-elements, transforms, and currentColor.

1. What Are Pure CSS Icons?

Pure CSS icons are shapes created without images or SVG files. They are made with CSS properties like borders, transforms, border-radius, and pseudo-elements.

Simple idea: One HTML element can become an icon by styling it with CSS.

2. Border Triangle

A triangle can be made from borders. The element has no width or height, so the borders become the visible shape.

Down Arrow 
<span class="triangle-down"></span>
.triangle-down {
  width: 0;
  height: 0;

  border-left: 10px solid transparent;
  border-right: 10px solid transparent;
  border-top: 16px solid currentColor;
}
The left and right borders are transparent. The top border creates the visible triangle.

3. Seeing All Four Borders

Before making three borders transparent, it helps to show all four border colors. This makes it easier to understand how the triangle technique works. 

.full-border-shape {
  width: 0;
  height: 0;

  border-top: 30px solid blue;
  border-right: 30px solid green;
  border-bottom: 30px solid purple;
  border-left: 30px solid orange;
}

Each border creates one triangle. Making three sides transparent leaves only one visible triangle.

4. Rotated Border Chevron

A chevron can be made from two borders on a small square. Rotating the square makes the shape point in a direction.

Continue 
<span class="chevron-right"></span>
.chevron-right {
  display: inline-block;
  width: 12px;
  height: 12px;

  border-top: 3px solid currentColor;
  border-right: 3px solid currentColor;

  transform: rotate(45deg);
}
The borders create an L shape. Rotating it 45 degrees makes it look like a right-pointing chevron.

5. Plus Icon with Pseudo-Elements

The ::before and ::after pseudo-elements give one HTML element two extra parts. 

<button class="add-button">
  <span class="plus-icon"></span>
  Add Item
</button>
.plus-icon {
  position: relative;
  width: 18px;
  height: 18px;
}

.plus-icon::before,
.plus-icon::after {
  content: "";
  position: absolute;
  background: currentColor;
}

.plus-icon::before {
  width: 18px;
  height: 3px;
  top: 7.5px;
  left: 0;
}

.plus-icon::after {
  width: 3px;
  height: 18px;
  top: 0;
  left: 7.5px;
}
::before creates the horizontal line and ::after creates the vertical line.

6. Basic Hamburger Icon

A hamburger icon uses the main element as the middle line. The two pseudo-elements create the top and bottom lines. 

<span class="hamburger"></span>
.hamburger,
.hamburger::before,
.hamburger::after {
  display: block;
  width: 24px;
  height: 3px;
  background: currentColor;
  border-radius: 2px;
}

.hamburger {
  position: relative;
}

.hamburger::before,
.hamburger::after {
  content: "";
  position: absolute;
  left: 0;
}

.hamburger::before {
  top: -8px;
}

.hamburger::after {
  top: 8px;
}

The main element needs position: relative so the pseudo-elements can be positioned around it.

7. Hamburger-to-Close Morph

Click the button below. The middle line disappears, while the top and bottom lines move to the center and rotate into an X.

Home Projects Contact 
<button
  class="menu-button"
  aria-expanded="false"
>
  <span class="hamburger"></span>
  <span class="button-text">Open Menu</span>
</button>
.hamburger,
.hamburger::before,
.hamburger::after {
  transition:
    top 300ms ease-in-out,
    transform 300ms ease-in-out,
    background 200ms ease-in-out;
}

.hamburger.is-open {
  background: transparent;
}

.hamburger.is-open::before {
  top: 0;
  transform: rotate(45deg);
}

.hamburger.is-open::after {
  top: 0;
  transform: rotate(-45deg);
}
const menuButton = document.querySelector("#menu-button");
const hamburger = document.querySelector(".menu-button .hamburger");
const buttonText = document.querySelector(".button-text");
const demoMenu = document.querySelector("#demo-menu");

menuButton.addEventListener("click", () => {
  const isOpen =
    menuButton.getAttribute("aria-expanded") === "true";

  menuButton.setAttribute(
    "aria-expanded",
    String(!isOpen)
  );

  hamburger.classList.toggle("is-open");
  demoMenu.hidden = isOpen;

  buttonText.textContent =
    isOpen ? "Open Menu" : "Close Menu";
});

8. Using currentColor

The value currentColor tells the icon to use the same color as its parent element.

Blue
Green
Purple 
.chevron-right {
  border-top: 3px solid currentColor;
  border-right: 3px solid currentColor;
}

.blue-example {
  color: #2563eb;
}

.green-example {
  color: #059669;
}

.purple-example {
  color: #7c3aed;
}
The icon CSS stays the same. Only the parent text color changes.

9. Reduced Motion

Some users prefer less animation. A reduced-motion media query removes the transition while allowing the icon to still change. 

@media (prefers-reduced-motion: reduce) {
  .hamburger,
  .hamburger::before,
  .hamburger::after {
    transition: none;
  }
}
The menu still opens and closes, but the icon changes instantly.

10. Accessibility

A CSS icon does not have its own accessible name. An icon-only button needs an aria-label or visually hidden text. 

<button aria-label="Add new item">
  <span
    class="plus-icon"
    aria-hidden="true"
  ></span>
</button>

The button receives the label. The decorative icon is hidden from screen readers with aria-hidden="true".

11. CSS Icons vs. SVG Icons

Use CSS Icons

  • Simple arrows and triangles
  • Hamburger and close icons
  • Small shapes used in one place
  • Simple morph animations

Use SVG Icons

  • Detailed or custom shapes
  • Logos and illustrations
  • Large icon sets
  • Icons reused across many pages
Rule of thumb: Use CSS for simple geometric shapes and SVG for detailed or reusable icons.
