CSS currentColor Demo

Use one color value to control text, borders, icons, shadows, and backgrounds.

What is currentColor?

currentColor is a CSS keyword that means: use the current text color.

This alert uses one color for the text, border, and shadow. 
.alert {
  color: #b91c1c;
  border: 2px solid currentColor;
  box-shadow: 0 2px 8px currentColor;
}

The border and shadow automatically match the text color. If you change color, everything updates.

Example 1: Status Badges

Each badge only changes the color property. The border and background tint update automatically.

Success Warning Danger 
.badge {
  color: var(--color-accent);
  border: 1px solid currentColor;
  background: color-mix(in srgb, currentColor 12%, transparent);
}

.badge--success { color: #16a34a; }
.badge--warning { color: #ca8a04; }
.badge--danger  { color: #dc2626; }

Example 2: Button with SVG Icon

SVG icons work great with currentColor. The icon can match the text color automatically. 

<path fill="currentColor" d="..." />

.btn {
  color: var(--color-accent);
  border: 1px solid currentColor;
}

.btn:hover {
  color: white;
  background-color: var(--color-accent);
}

Hover over the button. The text, icon, and border all turn white because they are all using currentColor.

Example 3: Blockquote

The wrapper uses an accent color for decorations. The paragraph inside resets the text back to normal.

One color controls the border and shadow, but the paragraph text stays readable.

.pullquote {
  color: var(--color-accent);
  border-left: 4px solid currentColor;
  box-shadow: -4px 0 12px currentColor;
}

.pullquote p {
  color: var(--color-text);
}

Important Gotcha

CSS does not run line by line. If you set color twice, the final value wins.

This box looks black, not red. 
.box {
  color: red;
  border: 2px solid currentColor;
  box-shadow: 0 0 5px currentColor;
  color: black;
}

The final color is black, so the border and shadow are black too.

currentColor in CSS Variables

You can store currentColor in a custom property, but it resolves where it is used.

Header border is navy
Footer border is gray
:root {
  --border-tint: currentColor;
}

.header {
  color: navy;
  border: 1px solid var(--border-tint);
}

.footer {
  color: gray;
  border: 1px solid var(--border-tint);
}

currentColor vs. Custom Properties

Use a custom property when you want a specific named color, like var(--color-accent).

Use currentColor when you want something to match the current text color.

  • Custom property: always uses a specific token color.
  • currentColor: follows the element’s current text color.
